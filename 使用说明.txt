AI 文件整理助手 - 使用说明
==============================

【运行环境】
- Windows 10 / 11（64 位），无需安装 Python 或任何软件
- 需要联网（分析时调用 DeepSeek AI 接口）

【首次使用：3 步】
1. 双击 AI文件整理助手.exe
   - 如弹出 Windows SmartScreen 蓝色警告：点“更多信息”→“仍要运行”
     （个人开发的软件没有购买签名证书，属正常现象，不是病毒）
2. 在打开的网页界面“基本设置”里填写：
   - 要整理的文件夹路径（例如 C://Users//你的名字//Desktop//文件）
   - DeepSeek API 密钥（去 https://platform.deepseek.com 注册，
     在“API keys”页面创建，新用户有免费额度，之后按量计费很便宜）
   - 【分类场景】选一个预设（学生学习 / 工作办公 / 科研论文 /
     求职应聘 / 财务票据 / 生活杂项），会自动填写分类要求；
     也可以在“自定义分类要求”里用大白话写，例如：
     “按大一到大四的课程分开”“所有简历单独一类”“分类控制在 8 类以内”
3. 保存设置后点“开始分析”，AI 会先给出【分类方案】（每个分类的名字、
   定义边界、预计装哪些文件），不会直接开始归类
4. 在页面的「分类方案」卡片里检查并修改（这是新增的关键一步）：
   - 直接改分类名、改说明（定义边界）
   - “删除”不要的分类；“合并到…”把某个分类并进另一个
   - 每个文件右侧的“移到…”下拉框可把文件改到别的分类
   - “未分配文件”区会列出方案里没覆盖到的文件，用下拉框归位
   - 改完点「保存方案」或直接点「按方案生成总表」（会自动先保存）
   - 分类太多看着累？可以折叠：
     · 刚分析完，所有分类默认是【收起】的，只显示分类名和文件数量，
       想细看某一类，点它最左边的小三角展开即可（再点一次收起）
     · 点「分类方案」这一行的标题 → 收起 / 展开整块方案
     · 「全部收起 / 全部展开」按钮 → 一键切换所有分类
     · 折叠状态记在浏览器里，关掉界面再打开仍保持
5. 生成《文件整理总表.xlsx》后，打开检查、点「开始归档」即可

【分类场景与自定义要求】
- 场景预设只是帮你预填文字，真正生效的是“自定义分类要求”文本框，可以随便改
- AI 分类时优先遵守你的要求（与默认规则冲突时以你的要求为准）
- 修改要求后再次点“开始分析”，会自动重新生成分类方案；
  已经分析过的文件仍走缓存，不会重复消耗额度
- 分类方案存在 scheme.json，可以反复修改；文件库或要求变了会提示重新生成

【注意事项】
- exe 放桌面等普通文件夹里运行即可，配置和缓存在 exe 同目录自动生成
- 支持：Word(docx)、PDF、PPT(pptx)、TXT；老版 .doc 需先另存为 .docx
- 分析消耗的是你自己 API Key 的额度，与开发者无关
- 运行中不要重复双击
