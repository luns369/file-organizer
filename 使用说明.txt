AI 文件整理助手 - 使用说明
==============================

【运行环境】
- Windows 10 / 11（64 位），无需安装 Python 或任何软件
- 需要联网（分析时调用 DeepSeek AI 接口）

【首次使用：3 步】
1. 双击 AI文件整理助手.exe
   - 如弹出 Windows SmartScreen 蓝色警告：点“更多信息”→“仍要运行”
     （个人开发的软件没有购买签名证书，属正常现象，不是病毒）
2. 在打开的网页界面“基本设置”里填写：
   - 要整理的文件夹路径（例如 C://Users//你的名字//Desktop//文件）
   - DeepSeek API 密钥（去 https://platform.deepseek.com 注册，
     在“API keys”页面创建，新用户有免费额度，之后按量计费很便宜）
   - 【分类场景】选一个预设（学生学习 / 工作办公 / 科研论文 /
     求职应聘 / 财务票据 / 生活杂项），会自动填写分类要求；
     也可以在“自定义分类要求”里用大白话写，例如：
     “按大一到大四的课程分开”“所有简历单独一类”“分类控制在 8 类以内”
   - 【分类层级】：自动 / 两级（一级/二级）/ 一级，见下面专门说明
3. 保存设置后点“开始分析”，AI 会先给出【分类方案】（每个分类的名字、
   定义边界、预计装哪些文件），不会直接开始归类
4. 在页面的「分类方案」卡片里检查并修改（这是新增的关键一步）：
   - 方案按【一级分类】分组显示：每一组的标题就是一级名（如“学习”），
     标题右侧写着“N 个二级 · M 个文件”；标题行最右边是“删除整组”
   - 组头的一级名可以直接改，改完这一组下面所有分类的一级名会一起变
   - 组里每张分类卡只填【二级名】（如“考公”），留空表示这一级不再细分
   - 分类卡里还能改“定义边界”、点“删除”去掉这个二级分类，
     用“合并到…”把它并进另一个分类
   - 每个文件右侧的“移到…”下拉框可把文件改到别的分类（下拉里显示完整层级名）
   - “未分配文件”区会列出方案里没覆盖到的文件，用下拉框归位
   - 改完点「保存方案」或直接点「按方案生成总表」（会自动先保存）
   - 分类太多看着累？可以折叠：
     · 刚分析完，所有【二级分类】默认是收起的（分组保持展开，先看总览），
       想细看某一类，点它最左边的小三角展开即可（再点一次收起）
     · 点【一级分组】标题最左边的小三角 → 收起 / 展开这一整组
     · 点「分类方案」这一行的标题 → 收起 / 展开整块方案
     · 「全部收起 / 全部展开」按钮 → 一键切换所有分组与分类
     · 折叠状态记在浏览器里，关掉界面再打开仍保持
5. 生成《文件整理总表.xlsx》后，打开检查、点「开始归档」即可

【分类层级：一级还是两级（新增）】
- 位置：基本设置里的「分类层级」下拉
  · 自动（默认）：内容跨度大、文件多时用两级，内容集中时只分一级
  · 两级：分类名一律写成“一级/二级”，例如“学习/考公”“工作/项目文档”
  · 一级：全部平铺，不建子文件夹，分类名里不出现“/”
- 归档效果：两级分类会建出两层文件夹，例如
    学习/考公/行测真题.pdf
    学习/考研/食品化学笔记.docx
    生活/家常菜谱.txt          （“生活”没分二级，就只有一层）
- 总表效果：表头分两行——第 1 行是一级分类（同一级的几列会合并、同一配色），
  第 2 行是二级分类；没分二级的分类第 2 行留空
- 改了层级后点“开始分析”，会自动重新设计分类方案；没改则复用原方案
- 想让 AI 只分一级、或者限定层级数量，直接在“自定义分类要求”里写，
  例如：“不要子分类，只分一级”“一级分类不要超过 5 个”——你的要求优先
- 老版本生成的总表（单行表头）也能正常读回，你手工改过的分类不会丢

【分类场景与自定义要求】
- 场景预设只是帮你预填文字，真正生效的是“自定义分类要求”文本框，可以随便改
- AI 分类时优先遵守你的要求（与默认规则冲突时以你的要求为准）
- 修改要求后再次点“开始分析”，会自动重新生成分类方案；
  已经分析过的文件仍走缓存，不会重复消耗额度
- 分类方案存在 scheme.json，可以反复修改；文件库或要求变了会提示重新生成

【越用越准：AI 会学习你的手动调整（新增）】
- 你在《文件整理总表》里改过的分类会被记下来（只认真正的改动，不会把 AI 自己的
  结果当成你的偏好）
- 下次点“开始分析”时，这些改动作为“归类偏好”喂给 AI：
  · 分类名会和你的习惯保持一致
  · 与这些文件类似的新文件，也会按同样的习惯归档
  · 方案页面顶部会显示“已学习你手动调整过的 N 条归类偏好”
- 改了总表分类后再点“开始分析”，会自动重新生成方案来体现你的偏好；
  没有新改动时仍复用原方案，不重复消耗额度
- 你手动改过的文件在归位时永远保留你的分类，其它文件按方案归位
- 小提示：第一次使用“学习”功能时，工具会先把你现有总表里的分类记为“基线”，
  从这之后再改总表才会被学习到

【注意事项】
- exe 放桌面等普通文件夹里运行即可，配置和缓存在 exe 同目录自动生成
- 支持：Word(docx)、PDF、PPT(pptx)、TXT；老版 .doc 需先另存为 .docx
- 分析消耗的是你自己 API Key 的额度，与开发者无关
- 运行中不要重复双击
